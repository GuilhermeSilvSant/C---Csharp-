# Sintaxes 1.0

## Consoles Write

- Console.WriteLine = Escreve Linhas , Ocupando Uma Linha de Espaço
- Console.Write = Escreve Linhas , Sem ocupar Linhas
- \n = Você tambem pode usar \n Para pular linha 

```csharp

  Console.WriteLine("TEXTO com Linha");
  Console.Write("\n--\nTEXTO sem linha");

```
